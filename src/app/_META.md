# /src/app - 路由与页面层

Next.js App Router 目录，包含所有页面路由、全局配置及 Google AdSense 合规法律页面。

## 文件清单

| 文件/目录 | 地位/作用 |
|-----------|----------|
| `page.tsx` | 首页（通用生产力计算器），路由入口 |
| `layout.tsx` | 根布局组件，包裹所有页面 |
| `globals.css` | 全局样式，包含 Tailwind 导入和自定义动画 |
| `calculator/` | pSEO 动态路由子目录 |
| `privacy/` | 隐私政策路由（GDPR / CCPA / Google DART 广告合规） |
| `terms/` | 服务条款路由（免责声明与工具使用边界） |
| `about/` | 关于我们路由（使命、行业算法方法论与 E-E-A-T） |
| `contact/` | 联系我们路由（工单表单与实时支持渠道） |
